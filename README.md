# Daily Fortune

A small morning ritual and a playable dice-and-card game.

Draw your possibilities, roll the dice, and drag each die into a card slot to decide which fortunes come true.

## Features

- 48 fortunes: 16 good, 16 neutral, and 16 bad.
- Six permanent power types, each with three upgrade ranks.
- A horizontal card spread above a bottom dice tray.
- Solid animated dice with mouse, touch, and keyboard-friendly placement.
- Prominent card effects and animated reveals showing what actually happened.
- Daily and Free Play modes with separate collections and journals.
- Browser-local progress, JSON import/export, and a downloadable offline HTML copy.
- Responsive layout and reduced-motion support.

## Play

Open `index.html` in a modern browser. No installation, build step, server, or external assets are needed.

For GitHub Pages, publish the `main` branch from the repository root.

## Basic rules

1. Draw your fortune cards and roll once.
2. Drag dice into matching card slots. Each die stays on one card until you move it.
3. Fulfill complete cards to reveal their effects. Rerolls and manipulation come from earned powers and card effects.
4. Resolve any choices, continue with the available dice, or finish the reading.
5. Keep permanent powers; another copy upgrades its kind instead of stacking it.

Progress is stored in your browser. Export progress before changing devices or clearing browser storage. The HTML download contains the clean app, not your saved readings.
